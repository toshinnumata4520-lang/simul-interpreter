プライバシーポリシー

このページは、日英同時通訳アプリ「同時通訳 JA⇄EN」（以下「本アプリ」）と、その「かんたん設定」機能における情報の取り扱いを説明するものです。

1. Googleログインで行うこと

「かんたん設定」では、利用者本人の操作によりGoogleアカウントでログインし、Google Cloud への一時的なアクセス許可（https://www.googleapis.com/auth/cloud-platform）を受け取ります。この許可は、次の目的にのみ使います。

  • 利用者本人のGoogleアカウント内に、本アプリ用のプロジェクトを作成する（既にあれば再利用する）
  • そのプロジェクトで Gemini API などの必要な機能を有効にする
  • Gemini API 専用に制限したAPIキーを作成し、本アプリに設定する

アクセス許可は利用者のブラウザ内でのみ使い、設定が終わった時点でGoogleに対して取り消します。作成したプロジェクト以外のデータを読んだり変更したりすることはありません。

2. 情報の保存場所

  • 作成したAPIキーと本アプリの設定は、利用者の端末のブラウザ内（ローカルストレージ）にのみ保存します。
  • 本アプリの運営者や第三者のサーバーに、APIキー・アクセス許可・Googleアカウントの情報を送信・保存することはありません。
  • Googleユーザーデータを販売したり、広告・その他の目的に使ったりすることはありません。

3. 通訳のために送信される情報

通訳時の音声や文字は、翻訳のため利用者のブラウザから直接 Google（Gemini API）へ送信されます。音声認識にはブラウザの機能（Apple / Google 等）を使います。これらの送信先での取り扱いは各社の規約に従います。Gemini API の無料枠では、送信内容がGoogleのサービス改善に使われることがあるため、個人情報や機密情報を話す場面では使わないでください。

4. 利用をやめるとき

ブラウザのサイトデータを削除すると、端末内のAPIキーと設定は消えます。作成されたプロジェクトとAPIキーは、利用者本人が Google Cloud コンソール から削除できます。
